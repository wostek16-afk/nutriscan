# NutriScan PWA

Coach nutrition IA — analysé par Claude.

## Setup GitHub Pages (1 fois)

1. Push ce repo sur GitHub : `wostek16-afk/nutriscan`
2. GitHub Actions build et déploie automatiquement
3. Va dans Settings → Pages → Source: `gh-pages` branch
4. Ton app sera sur : `https://wostek16-afk.github.io/nutriscan`

## Ajouter à l'écran d'accueil iOS

1. Ouvre `https://wostek16-afk.github.io/nutriscan` dans Safari
2. Tap le bouton partage (carré avec flèche)
3. "Sur l'écran d'accueil"
4. Done — icône NutriScan sur ton home screen 🎉
